# Simple Todo List

A beginner-friendly todo list application built with HTML, CSS, and JavaScript.

## Features

- ✅ Add new todo items
- ✅ Mark todos as complete/incomplete
- ✅ Delete todo items
- ✅ Clean and simple interface
- ✅ Keyboard support (press Enter to add todos)

## How to Use

1. Open `index.html` in your web browser
2. Type a todo item in the input field
3. Click "Add Todo" or press Enter
4. Use the "Complete" button to mark items as done
5. Use the "Delete" button to remove items

## Files

- `index.html` - The main HTML structure
- `style.css` - Styling and layout
- `script.js` - JavaScript functionality

## Perfect for Beginners

This project uses basic HTML, CSS, and JavaScript concepts that are perfect for learning:
- DOM manipulation
- Event listeners
- CSS styling
- Basic JavaScript functions
- Array methods
